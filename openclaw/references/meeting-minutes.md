# 会议纪要大师 (meeting-minutes)

## 定位

将会议录音、文字记录或手写笔记转化为结构化纪要，含要点摘要、决策记录、价值评审和行动项跟踪。适用于项目全生命周期各类会议。

> **PMBOK 第八版对齐**：Governance + Stakeholders 绩效域 · Closing 聚焦领域（也贯穿全周期） · 原则：成为负责任的领导者、建设赋能文化

## 工作流

```
输入会议记录/录音/笔记
  → 识别会议类型和议程
  → 提取要点和讨论内容
  → 提取决策和行动项
  → 价值实现检查（第八版新增）
  → 相关方参与评估（第八版新增）
  → 结构化整理
  → 输出 Markdown 纪要文件
```

## 输入要求

- **必需**：会议内容（文字记录、录音转写文本、或手写笔记）
- **推荐**：会议主题、参会人名单、会议日期
- **可选**：会议议程、相关文档、项目价值目标定义

若输入不足，追问以下要素（最多 1 轮）：
1. 会议类型（决策会/站会/评审会/头脑风暴/复盘会/价值评审会）
2. 参会人员
3. 会议日期和时长
4. 项目开发方法（影响会议类型和纪要格式）

## 会议类型识别

| 类型 | 特征 | 纪要重点 |
|------|------|----------|
| 决策会 | 需要在选项中做选择 | 决策记录 + 理由 + 备选方案 |
| 日报/站会 | 短时、高频、每人简述 | 昨日完成 + 今日计划 + 阻塞项 |
| 评审会 | 审查交付物或方案 | 评审结论 + 修改意见 + 复审安排 |
| 头脑风暴 | 收集创意和方案 | 创意清单 + 分组归类 + 后续筛选 |
| 复盘会 | 回顾项目/阶段表现 | 经验总结 + 改进措施 + 行动项 |
| 客户沟通 | 与外部相关方交流 | 客户需求 + 承诺事项 + 风险提示 |
| **价值评审会**（第八版新增） | 评估项目价值实现进展 | 价值指标对比 + 偏差分析 + 价值调整决策 |

## 结构化提取规则

### 要点提取

1. 去除口语化表达（"嗯"、"那个"、"就是说"等）
2. 合并重复内容
3. 按议题分组，而非按时间顺序
4. 保留关键数据、日期、人名

### 决策记录

每个决策须包含：
- 决策内容
- 决策人（单一负责人，体现"成为负责任的领导者"原则）
- 决策依据/背景
- 备选方案（如有）
- 生效条件/时间
- 价值影响（第八版新增：该决策对项目价值目标的影响）

### 行动项提取

每个行动项须满足 5W：
- **What**：做什么（具体可执行）
- **Who**：负责人（单一负责人，非"团队"）
- **When**：截止日期
- **Why**：关联的决策或价值目标
- **How**：验收标准（如有）

若原始记录中缺少上述要素，在纪要中标注 `[待确认]` 并列入行动项跟踪表。

## 价值实现检查（第八版新增 — "聚焦价值"原则）

在所有会议纪要中增加"价值实现检查"板块，评估本次会议相关工作的价值进展：

| 价值目标 | 上期指标值 | 本期指标值 | 进展趋势 | 偏差/风险 | 调整建议 |
|----------|-----------|-----------|----------|-----------|----------|
| | | | ↑/↓/→ | | |

> 若项目尚处于早期阶段（无价值指标数据），简注"价值目标待定义"并列入行动项。

## 相关方参与评估（第八版新增 — Stakeholders 绩效域）

在涉及相关方沟通的会议（客户沟通、决策会、评审会）中，增加相关方参与评估：

### 参与度评估矩阵（PMBOK 第八版 Figure 2-36）

| 相关方 | 当前参与度 | 期望参与度 | 差距 | 沟通策略 |
|--------|-----------|-----------|------|----------|
| {相关方A} | 不了解/抵制/中立/支持/领导 | 不了解/抵制/中立/支持/领导 | {差距描述} | |

参与度等级定义：
- **不了解**（Unaware）：不知道项目存在
- **抵制**（Resistant）：知道但抵制变化
- **中立**（Neutral）：了解但不积极支持
- **支持**（Supportive）：积极支持项目
- **领导**（Leading）：主动推动项目成功

## 裁剪指导

根据项目开发方法调整会议类型和纪要格式：

| 开发方法 | 主要会议类型 | 纪要格式 | 特殊处理 |
|----------|-------------|----------|----------|
| **预测型** | 启动会、里程碑评审、阶段评审、收尾会 | 完整结构化纪要 | 正式决策记录，归档要求高 |
| **适应型（敏捷）** | 每日站会、迭代计划、迭代评审、回顾会 | 轻量纪要 | 站会纪要简化为"完成/计划/阻塞"三栏，回顾会含改进行动项 |
| **混合型** | 预测型里程碑 + 适应型迭代 | 按会议类型调整 | 正式会议用完整纪要，迭代会议用轻量纪要 |
| **价值评审会**（所有方法） | 定期（月度/季度） | 价值实现检查表 | 跟踪价值指标趋势，评估是否需调整价值目标 |

详细裁剪建议见 [tailoring-guide.md](tailoring-guide.md)。

## 工具使用

- 读取会议记录文件：Read 工具（支持 TXT/Markdown/Word）
- 搜索相关项目背景：Grep 工具
- 搜索会议模板或历史纪要：Grep 工具
- AI 自动化（Automation 层）：会议内容自动结构化、行动项自动提取
- AI 辅助（Assistance 层）：相关方参与度评估、价值指标趋势分析
