# 进度管家 (progress-manager)

## 定位

对比计划与实际进度，计算偏差指标，分析原因并给出调整建议。适用于项目执行和监控阶段。

> **PMBOK 第八版对齐**：Schedule + Finance 绩效域 · Executing/Monitoring & Controlling 聚焦领域 · 原则：聚焦价值、将质量融入过程

## 工作流

```
输入进度数据和计划数据
  → 确定项目开发方法 → 参考裁剪指导选择进度跟踪方式
  → 计算偏差指标（SV、CV、SPI、CPI）
  → 计算价值实现偏差（第八版新增）
  → 分析偏差原因
  → 生成调整建议
  → 输出偏差分析 Markdown 报告
```

## 输入要求

- **必需**：项目计划（任务清单、计划开始/结束日期、预算）
- **必需**：实际进度数据（已完成任务、实际开始/结束日期、实际消耗）
- **推荐**：里程碑清单、资源分配表、价值目标定义

若输入不足，追问以下要素（最多 2 轮）：
1. 数据截止日期（报告日期）
2. 完成标准定义（什么是"完成"）
3. 当前进度数据的来源（周报/系统导出/人工估算）
4. 项目开发方法（预测型/适应型/混合型）— 影响 EVM 适用性和替代指标
5. 项目价值目标及其衡量指标（第八版新增）— 用于价值实现偏差计算

## 偏差指标计算

### 挣值管理（EVM）核心指标

| 指标 | 名称 | 公式 | 含义 |
|------|------|------|------|
| PV | 计划价值 | 计划完成工作的预算成本 | 截至报告日应完成的预算 |
| EV | 挣值 | 已完成工作的预算成本 | 实际完成量 × 预算单价 |
| AC | 实际成本 | 已完成工作的实际成本 | 实际花费 |
| SV | 进度偏差 | EV - PV | >0 提前，<0 滞后 |
| CV | 成本偏差 | EV - AC | >0 节约，<0 超支 |
| SPI | 进度绩效指数 | EV / PV | >1 提前，<1 滞后，=1 按计划 |
| CPI | 成本绩效指数 | EV / AC | >1 节约，<1 超支，=1 按预算 |
| EAC | 完工估算 | BAC / CPI | 按当前趋势的最终成本预测 |
| ETC | 完工尚需估算 | EAC - AC | 剩余工作预计还需花费 |
| VAC | 完工偏差 | BAC - EAC | 最终预算偏差 |

### 价值实现偏差（第八版新增 — "聚焦价值"原则）

EVM 衡量的是进度和成本偏差，但"按时按预算完成"不等于"价值已实现"。第八版要求同时跟踪价值实现偏差：

| 指标 | 名称 | 公式 | 含义 |
|------|------|------|------|
| VP | 计划价值实现 | 截至报告日计划实现的价值指标值 | 按计划应达到的价值 |
| VA | 实际价值实现 | 截至报告日实际实现的价值指标值 | 实际达到的价值 |
| VV | 价值偏差 | VA - VP | >0 超预期，<0 未达预期 |
| VPI | 价值绩效指数 | VA / VP | >1 超预期，<1 未达预期 |

> 价值指标示例：患者满意度评分、系统使用率、流程效率提升百分比。在需求拆解阶段（req-decomposer）定义的项目价值目标基础上计算。

### 偏差等级判定

| SPI/CPI/VPI | 等级 | 状态 | 建议行动 |
|-------------|------|------|----------|
| ≥ 1.1 | 优秀 | 绿色 | 保持现状，考虑提前交付或提升价值目标 |
| 0.9 - 1.1 | 正常 | 蓝色 | 按计划执行，常规监控 |
| 0.8 - 0.9 | 预警 | 黄色 | 分析原因，制定纠偏措施 |
| < 0.8 | 告警 | 红色 | 立即干预，上报管理层 |

## 偏差原因分析框架

从以下维度分析偏差根因：

| 维度 | 分析要点 |
|------|----------|
| 范围 | 需求变更是否影响进度？范围蔓延？ |
| 资源 | 人员到位情况？能力匹配？资源冲突？ |
| 估算 | 原始估算是否合理？低估了哪些因素？ |
| 依赖 | 外部依赖延迟？前置任务未按时完成？ |
| 质量 | 返工率？缺陷修复耗时？（第八版"将质量融入过程"原则） |
| 外部 | 供应商延迟？审批流程耗时？不可抗力？ |
| **价值**（第八版新增） | 已完成工作是否实际产生了预期价值？价值目标是否需要调整？ |

## 裁剪指导

根据项目开发方法选择进度跟踪方式：

| 开发方法 | 主要跟踪指标 | EVM 适用性 | 特殊处理 |
|----------|-------------|-----------|----------|
| **预测型** | EVM 全套指标（SV/CV/SPI/CPI/EAC） | 完全适用 | 标准偏差分析流程 |
| **适应型（敏捷）** | 燃尽图（Burndown）、速率（Velocity）、迭代完成率 | 不直接适用 | 用故事点替代 PV/EV，跟踪迭代速率趋势 |
| **适应型（看板）** | 周期时间（Cycle Time）、吞吐量（Throughput）、WIP 数 | 不适用 | 用累积流图（CFD）跟踪流动效率 |
| **混合型** | EVM（上层）+ 燃尽图/速率（执行层） | 部分适用 | 上层用 EVM 跟踪整体偏差，执行层用敏捷指标 |
| **价值跟踪（所有方法）** | VPI 价值绩效指数 | 均适用 | 价值指标与开发方法无关，始终跟踪 |

详细裁剪建议见 [tailoring-guide.md](tailoring-guide.md)。

## 工具使用

- 读取进度数据文件：Read 工具（支持 Excel/CSV/Markdown）
- 计算偏差指标：Bash 运行 Python 脚本（EVM + 价值偏差计算）
- 生成可视化建议（甘特图/燃尽图/累积流图）：Bash 运行 Python（matplotlib/plotly）
- 搜索已有项目档案：Grep 工具
- AI 辅助（Assistance 层）：自动识别偏差模式，匹配历史纠偏经验
- AI 增强（Augmentation 层）：预测完工趋势，推荐最优纠偏方案
