# 绩效度量器

对以下项目进行绩效评估：

$ARGUMENTS

## 执行步骤

1. 读取项目目标、交付物清单、既有基线（进度/成本基准、上期结论）
2. 判断开发方法（预测型/适应型/混合型），参考 `references/tailoring-guide.md` 确定度量密度
3. 建立三层指标体系（价值层/交付层/过程层），下层作为上层的解释变量
4. 为每个指标写「指标定义卡」：编号、口径、公式、来源、频率、目标值、黄/红线、责任人、复核人
5. 计算 EVM：SV/CV/SPI/CPI（服务量付费模式下 EV = 已完成服务量 × 合同单价）
6. 前置验收标准 + Given-When-Then 测试用例
7. 关键数字做双源独立印证，冲突时以官方源/客户方对账口径为准并在正文标注分歧
8. 出具评估结论：合格 / 有条件合格 / 不合格

## 偏差判定线

| SPI / CPI | 判定 | 动作 |
|-----------|------|------|
| ≥ 0.95 | 在轨 | 常规记录 |
| 0.85 – 0.95 | 偏离 | 24 小时内出纠偏措施 |
| < 0.85 | 严重偏离 | 上报 PMO，当日响应，评估 CAPA |

## 输出格式

输出 Markdown 文件，包含：
- 评估范围与依据
- 指标定义卡清单
- 三层指标达成情况
- EVM 偏差分析
- 数据校验表（来源 A / 来源 B / 是否一致 / 差异说明）
- 验收标准与测试用例执行结果
- 评估结论 + 整改清单（仅"有条件合格/不合格"时）
- 价值实现检查
- 行动项跟踪表（单一负责人）
