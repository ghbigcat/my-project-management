# 过程观测器

对以下项目进行状态观测：

$ARGUMENTS

## 执行步骤

1. 确认观测对象与阈值（口径须复用 `references/evaluation.md` 的指标定义卡，不得另行定义）
2. 采集数据：定期采集 + 事件驱动两条通道
3. 数据 → 信息：与基线比较，计算偏差，判定绿/黄/红
4. 信息 → 报告：按受众裁剪篇幅与粒度
5. 触发预警并给出升级路径
6. 记录事件日志（不可事后补记）
7. 异常闭环：列入问题日志 → 纠正措施 → 验证关闭

## 告警分级

| 级别 | 触发条件 | 响应时限 | 处置 |
|------|----------|----------|------|
| 绿 | 偏差 ≤ 5%，且在轨 | 常规周期报告 | 项目内记录 |
| 黄 | 偏差 5%-15%，或趋势连续两期恶化 | 24 小时内 | 项目经理处置，下期复验 |
| 红 | 偏差 > 15%，或触碰合规红线，或关键里程碑失守 | 当日 | 上报 PMO，评估变更或 CAPA |

> 合规红线单列：AE/PV 上报、GCP 文件、审计追踪、隐私保护，无论偏差大小一律按红色处理。

## 报告受众裁剪

| 受众 | 频率 | 篇幅 | 重点 |
|------|------|------|------|
| 决策层 | 月度 | 1 页 | 红黄绿状态 + 3 个关键偏差 + 待决事项 |
| 管理层 | 双周 | 3 页 | 指标趋势 + 根因 + 行动项进度 |
| 执行层 | 周 | 明细 | 明细数据 + 待办 + 风险提示 |

## 输出格式

输出 Markdown 文件，包含：
- 总体状态（绿/黄/红 + 一句话结论）
- 指标观测表（含与上期趋势）
- 数据校验表
- 黄/红指标的偏差根因分析
- 事件日志（本期）
- 端到端追踪（1-2 条关键链路）
- 预警与升级
- 异常闭环台账
- 价值实现检查
- 行动项跟踪表（单一负责人）
