# 风险雷达

对以下项目进行风险评估：

$ARGUMENTS

## 执行步骤

1. 识别项目风险（来源：范围/进度/成本/资源/技术/外部/可持续性）
2. 对每个风险进行概率-影响评估（1-5 级）
3. 生成概率-影响矩阵（5×5）
4. 为每个风险选择应对策略（规避/转移/减轻/接受/上报）
5. 指定风险责任人（单一负责人）
6. 识别可持续性风险（环境合规/社会责任/资源可持续/ESG 监管）

## 输出格式

输出 Markdown 文件，包含：
- 风险登记册（编号/描述/类别/概率/影响/风险等级/策略/责任人/状态）
- 概率-影响矩阵（5×5 表格）
- 可持续性风险评估
- 行动项跟踪表
