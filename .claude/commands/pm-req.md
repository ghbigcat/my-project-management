# 需求拆解助手

将以下项目需求拆解为可执行的任务清单：

$ARGUMENTS

## 执行步骤

1. 识别项目类型（预测型/适应型/混合型），若无法判断则询问用户
2. 按 WBS 100% 原则分解需求（每层子任务之和 = 父任务 100%）
3. 对每个工作包进行 INVEST 验证（独立/可协商/有价值/可估算/小巧/可测试）
4. 标注 MoSCoW 优先级（Must/Should/Could/Won't）
5. 为每条需求标注对项目价值目标的贡献（价值映射）
6. 评估可持续性影响（社会/环境/经济三维度）

## 输出格式

输出 Markdown 文件，包含：
- 元信息头（项目名称、日期、能力名称、项目类型）
- WBS 分解树（层级编号 + 任务名称 + 责任人 + 工作量估算）
- 价值映射表（需求 → 价值目标 → 贡献度）
- 可持续性影响评估
- 行动项跟踪表（单一负责人）
