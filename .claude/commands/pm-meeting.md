# 会议纪要大师

将以下会议内容转为结构化纪要：

$ARGUMENTS

## 执行步骤

1. 判断会议类型（站会/评审/回顾/规划/价值评审/风险/收尾）
2. 提取议题分组和讨论要点
3. 记录关键决策（决策内容/决策人/依据/影响范围）
4. 提取行动项（5W：Who/What/When/Where/Why）+ 单一负责人
5. 价值实现检查（本次会议对项目价值目标的推进）
6. 相关方参与评估（5 级：Unaware → Resistant → Neutral → Supportive → Leading）

## 输出格式

输出 Markdown 文件，包含：
- 元信息头（会议类型/日期/参会人/会议目标）
- 议题与讨论要点
- 关键决策记录
- 价值实现检查
- 相关方参与评估
- 行动项跟踪表（5W + 单一负责人 + 截止日期 + 优先级 + 状态）
