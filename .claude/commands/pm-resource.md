# 资源优化器

对以下项目进行资源优化和负载均衡：

$ARGUMENTS

## 执行步骤

1. 构建团队成员技能矩阵（成员 × 技能 × 熟练度）
2. 计算人员-任务匹配度（技能匹配度 + 经验匹配度 + 可用性匹配度）
3. 评估当前负载均衡（负载均衡系数 = 实际工时 / 平均工时）
4. 识别过载和闲置成员
5. 生成优化方案（任务重分配 + 关键路径保护）
6. 评估赋能文化建设机会（成长型分配 + 团队赋能度评分）
7. 评估资源可持续性（人员可持续/技能可持续/资源消耗）

## 输出格式

输出 Markdown 文件，包含：
- 技能矩阵表
- 人员-任务匹配度评分表
- 负载均衡分析（当前 vs 优化后）
- 资源优化方案
- 赋能文化建设建议
- 可持续资源评估
- 行动项跟踪表
